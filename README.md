# Mediflash - Pokedex Interview

## Launch the application

In client folder, launch yarn start to start the frontend

In server folder, launch yarn run start to start the backend

If you want to change the number of pokemons displayed, change limit number in fetch-pokemons.inbound.dto.ts file
